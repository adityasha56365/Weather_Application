# 🌦️ Weather Application

A simple, responsive, and user-friendly Weather Application that helps users explore weather conditions through a clean and intuitive interface.

🌐 **Live Demo:** [Weather Application](https://weather-application-eta-puce.vercel.app/)

---

## 📌 About the Project

The Weather Application is a web-based project designed to provide users with an accessible interface for checking weather information.

The project focuses on a clean user interface, responsive design, and a smooth user experience across different screen sizes.

## ✨ Features

- 🌤️ **Weather Interface** – A clean interface for exploring weather information.
- 📱 **Responsive Design** – Designed to work across desktop and mobile screens.
- 🎨 **Modern UI** – An attractive interface with weather-themed visuals.
- 🌍 **Easy to Use** – Simple navigation and an intuitive user experience.
- ⚡ **Lightweight Application** – Built using core web technologies.

## 🛠️ Technologies Used

- **HTML5** – Structures the application.
- **CSS3** – Handles styling, layout, and responsiveness.
- **JavaScript** – Implements interactive functionality.
- **Vercel** – Hosts the deployed application.
- **Git & GitHub** – Used for version control and project hosting.
